# Material Symbols Extended

This repository contains modified verions of [Google Material Symbols](https://github.com/google/material-design-icons/) (which is licensed under the Apache License 2.0) and is not affiliated with Google.

An extended version of static Material Symbols Outlined fonts containing extra icons as well as the icons in the original font. The fonts have an optical size variations of 24px and 48px, each with a filled and non-filled variant. Ligatures for the fonts are the same for the original Material Symbols (e.g. `person`, `more_horiz`) and for the extra icons, prepend with an underscore (e.g. `_folder_home`).
